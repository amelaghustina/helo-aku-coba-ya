Cara Upload Website Ini ke GitHub Pages

Gratis selamanya & bisa dipasang di bio CV / Instagram / LinkedIn Amel

1. Simpan File sebagai index.html

Salin seluruh kode ini dan simpan di komputer atau HP Anda dengan nama persis index.html (huruf kecil semua).

2. Buat Repository Baru di GitHub

Login ke github.com, klik tombol "+" (New Repository), beri nama misalnya portofolio-amel, pilih Public, lalu klik Create repository.

3. Upload File index.html

Klik link "uploading an existing file", pilih file index.html tadi, lalu klik tombol hijau Commit changes.

4. Aktifkan GitHub Pages

Buka tab Settings → menu Pages di sisi kiri → ubah Branch dari None menjadi main → klik Save. Tunggu 1-2 menit, link website Amel siap dibagikan!
